## 简介 🤔

项目使用PFC6.0软件，环境为3D。项目实现了无粘结（nobound）土壤颗粒的真三轴仿真。项目代码是在《颗粒流（PFC5.0）数值模拟技术及应用 (石崇) 》的基础上，根据PFC6.0的新语法和功能，适当修改而来。  

## 使用 ⭐

由于PFC软件会将窗口布局等信息保存在项目文件 `*.*prj`文件中，所以为了commit历史的清晰简洁，删除了 `prj` 文件。如果想在图形界面中运行该代码，请自行创建项目文件。  

### 使用CLI运行 🖥️

在项目目录下运行 `pfc3d600_console.exe` *(用户应自行搜索该程序所在位置，通常在安装目录下 `PFC600/exec64` 中)* 。然后执行以下命令  
```
program call 'main.py'
```

### 修改输入参数 🛠️

所有相关参数 *（至少与作者所进行的研究相关的参数）* 已经抽象到 `input.ini` 中，相关注释已经说明。  

### 输出 💾

输出内容会保存在 `Result` 文件夹下。在这个文件夹下， `makefile` 提供了一些打包常用命令。
